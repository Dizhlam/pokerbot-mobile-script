♠ PokerBot add-on

Plays Texas Hold'em for you on kobrapoker.com (play money) right in your browser, on a phone or a computer. It explains every decision, sits down at your tables by itself, learns how other players play and keeps your stats.

Android: Firefox + Tampermonkey
  1. Install Firefox from the Play Store (Chrome on Android can't run add-ons).
  2. In Firefox: menu ⋮ → Extensions (Add-ons) → find Tampermonkey → Add.
  3. Open this page in Firefox and tap the green Install PokerBot button below → Tampermonkey shows the add-on → Install.
  4. Open kobrapoker.com/play in Firefox. Turn the phone sideways for a bigger table.
iPhone / iPad: Safari + Userscripts (free)
  1. Install Userscripts from the App Store (free, by Justin Wasack). Open it once and tap Set Userscripts Directory (any folder is fine).
  2. Settings → Apps → Safari → Extensions → Userscripts: turn it on and allow it on kobrapoker.com (or All Websites).
  3. Open this page in Safari and tap Install PokerBot below. Safari shows the code: tap the extensions icon in the address bar (puzzle piece or ᴀA) → Userscripts → Install.
  4. Open kobrapoker.com/play in Safari. Turn the phone sideways for a bigger table.
Computer: Chrome, Edge or Firefox + Tampermonkey
  1. Install Tampermonkey from your browser's extension store.
  2. Chrome / Edge only: open the extension's Details and turn on Allow user scripts (Tampermonkey shows how).
  3. Click Install PokerBot below → Install.
  4. Open kobrapoker.com/play. F8 starts/stops the bot at the current table.

Using it

  1. Log in to Kobra as usual. Tick Remember password so the browser keeps you logged in. PokerBot never sees or stores your password.
  2. Tap the gold ♠ button at the bottom left to open the panel.
  3. Under My tables, add tables by name (or tap Pick from Kobra's table list).
  4. Press ▶ Play. The bot finds a free seat, buys in and plays. ■ Stop stops it; Leave leaves after the current hand.

Settings: play style (careful, normal, aggressive), buy-in, leave at 2× (lock in a win), stop-loss, leave when the table is full, thinking time. Stats shows your results with real card icons, Players shows what it learned about opponents, Log shows every decision and why.

Phones: keep the Kobra tab open and in front. The bot keeps the screen on while it plays, but phones pause hidden tabs and locked screens. Plug the phone in for long sessions.

Updates

Nothing to do: every time Kobra opens, the add-on loads the newest version from this page. Your add-on manager also checks for updates by itself (Tampermonkey about once a day; in Userscripts you can tap Check for updates).

Privacy

Everything (settings, stats, learned players) is saved only in your own browser. The add-on talks to nothing except the Kobra page you have open and this page (to download updates). Play-money tables only.
